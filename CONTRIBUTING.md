# Contributing

## Purpose reminder

This list exists to help Staff engineers **decide** how to run agents — not to maximize link count.

## Checklist for a new item

- [ ] Maps to at least one criterion: scope · MCP/tools · HITL · evidence · vendor-agnostic
- [ ] Public URL, no paywalled-only pitch
- [ ] One sentence: *why a squad would use this*
- [ ] Not a duplicate of an existing entry

One item per PR. PT or EN OK.
